# Syrové sádlo
Se podle uložení v těle vepře rozděluje na:
1. **Hřbetní sádlo** — nejjakostnější
2. **Plsní sádlo (z břicha)** — méně jakostí, škvaří se
3. **Střevní sádlo (obaluje střeva)** — škvaří se
4. **Kruponové sádlo (podkožní)** — škvaří se

# Škvařené sádlo
Vyrábí se dvěma způsoby:
1. **Suchou cestou (škvařením)** — sádlo je chuťově výraznější a trvanlivější, ale zbytky masitých tkání ([[Výrobky ze sádla#Vepřové škvarky|škvarky]]) se mohou připálit
2. **Mokrou cestou (vytavováním)** — modernější způsob, sádlo má jemnější chuť a vůni, nevýhodou je kratší trvanlivost

# Tržní druhy sádla
- **Domácí sádlo** — většinou ze hřbetního sádla, škvařené (suchou cestou)
- **Sádlo — I. jakost** — z jakéhokoliv druhu sádla, získané suchou či mokrou cestou
- **Sádlo — II. jakost** — ze střevního sádla — určeno pro průmyslové zpracování
