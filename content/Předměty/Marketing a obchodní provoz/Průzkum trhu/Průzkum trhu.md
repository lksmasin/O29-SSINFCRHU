# Co je to průzkum trhu
- Získávání informací o zákaznících a trhu
- Pomáhá firmám lépe se rozhodovat
- Průzkum trhu = klíč k úspěchu

**Zjišťuje**
- Co zákazníci chtějí
- Kolik jsou ochotni zaplatit
- Jak se chovají

# Proč je důležitý
- Snižuje riziko podnikání
- Pomáhá vytvořit lepší produkt
- Umožňuje porozumět zákazníkům
- Pomáhá porazit konkurenci

# Druhy průzkumů
- Primární výzkum — vlastní sběr dat
- Sekundární výzkum — existující data

# Metody průzkumů
- [[Dotazník]]
- Rozhovor
- Pozorování
- Experiment
